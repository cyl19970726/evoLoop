# 复盘报告的有界表达

供撰写或重整旧稿时使用；调查范围、独立QA和提交仍按Skill及相应引用。先写下读者带来的问题和读完应能作出的判断，再按理解顺序安排材料。结论先说改变了什么、为何改变、谁接手及下一次怎样验证；每段只承担一个解释任务。保留会改变原因、责任或取舍判断的事实、限定与反例，精确ID、重复操作和完整账目可放到可回查的证据处。不要让读者翻附件才能理解中心论证，也不要在每段重复通用边界而打断主线；会限制某项结论的条件留在该结论旁。

用本轮真实对象串成连续案例：**起点与当时可得依据 → 发现了什么（包括反例）→ 谁决定并做了什么 → 观察到的结果及消费 → 认识怎样改变、下一步为何不同**。可跨阶段接续同一目标，避免把一件事拆散到多张表。证据缺一环就明确停在已知处：后续出现相似现象时，按原始原因、条件和动作判断是同类复发还是新问题；只见表面相似就标为待辨，不为故事完整编造因果或用户使用。

图用来回答本轮具体问题。按实际任务、人物、Session和状态画职责关系、流程或状态变化，标出已观察、提议及未知的连接；图旁说明关键分支和证据。通用产品总图可作背景引用，不能顶替本轮运行图。数字写清对象、单位、分母或比较基线、观察时段与时区，以及它为何影响决定；时间区分执行、排队、验收等口径，并行区间不重复相加。截图只在能说明关键界面状态或读者经历时就近放置，注明版本/时间、可证明的范围和不能外推之处。

改旧稿时可临时列一份**原文细节保留清单**：逐项标记关键事实、反例、判断变化和来源在新主文或可回查证据中的位置，检查删减是否改变含义。它是编辑辅助，不是新永久表、固定章节或案例数量门槛。完成后以固定新稿交独立QA，让审阅者自行判断读者能否复述变化、选下一步，并对照旧稿发现误删；独立入口与盲审边界见[报告QA](report-qa.md)。

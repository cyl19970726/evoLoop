| 编号 | 方向 | 对文档与实现的影响 |

## 仍未选定或未实施

- 知识后端的最终采用及部署方式。nashsu 可继续作阅读整理候选，当前不建议直接作共享认知权威。
- harness 应用语言、框架、调度进程与运行状态持久化实现。文档工具使用 Node.js 不代表应用技术栈已定。
- 飞书实际租户、表结构、权限与并发/事件能力的现场验证。
- 首个运行时适配范围，尤其是唤醒、派发结果核对和重启后恢复。
- 公开文档站的域名、托管、自动发布和持续运维；公开 Git 仓库与部署文档站是两个状态。
- 项目许可证。公开源码可阅读不等于已选择某种开源许可证。
